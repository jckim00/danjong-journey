# 조선 왕조 이야기 — 단종 편

단종의 즉위에서 복권까지를 실제 답사 공간을 따라 구성한 역사 기행 시리즈입니다.

## 답사 순서

1. ①·② 경복궁 — 즉위와 취약한 왕권
2. ③·④ 사육신묘·정업원터 — 충과 기다림
3. ⑤ 사릉 — 정순왕후의 긴 삶과 복권
4. ⑥ 청령포·관풍헌·자규루 — 유배와 마지막 시간
5. ⑦ 장릉 — 버려진 무덤에서 왕릉으로
6. ⑧ 종묘 영녕전 — 241년 뒤 돌아온 왕

## 서사의 중심

왕이 되기로 선택한 것이 아니었다. 세자였기 때문에 왕이 되어야 했다. 그리고 왕좌를 잃은 뒤 단종의 이야기는 한 사람의 비극을 넘어, 조선이 무엇을 적통으로 여기고 무엇을 충절과 명분이라 불렀는지를 묻는 역사가 되었다.

경복궁에서 시작해 사육신묘·정업원터·사릉·청령포·관풍헌·장릉을 지나 종묘 영녕전까지 이어집니다.
